# YarnMeld

YarnMeld is a cloud-based high-performance platform that utilizes real-time auto-scaling capabilities as a unified job manager and optimizer.

YarnMeld is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- YarnMeld is a cloud-based high-performance
- platform that utilizes real-time auto-scaling
- capabilities as a unified job

- python

- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/YarnMeld.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

YarnMeld is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
